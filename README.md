# LINGRID legal pages

Redirect stubs for the old LINGRID legal addresses (the pages moved to https://beydadonmezz.github.io/lingrid/)
plus the data files the app downloads (app/). Served by GitHub Pages at
https://beydadonmezz.github.io/lingrid-site/ . Do not unpublish. Generated from `legal/build.py` in the (private) app repository;
do not edit here.

Every HTML file here is a redirect stub to https://beydadonmezz.github.io/lingrid/ . `app/**` stays byte-identical
(shipped app versions fetch it) and is mirrored at https://beydadonmezz.github.io/lingrid/app/ : every data publish
runs both `scripts/publish-legal-web.sh` and `scripts/publish-legal.sh` in the app repo.
